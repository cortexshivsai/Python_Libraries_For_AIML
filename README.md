The repository starts with the fundamentals of numerical computing using **NumPy** and progressively moves toward **data analysis, visualization, machine learning, deep learning, NLP, computer vision, Generative AI, and AI engineering**.

# 🛠️ Setup

Clone the repository:

```bash
git clone https://github.com/<your-username>/python-libraries.git
cd python-libraries
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

Activate it on Linux/macOS:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
